# sanie-ftp

Public file drop for Michael Sanie.  Files placed here get a direct link that any browser, program, or AI tool can read.

## Link pattern

Every file follows the same URL pattern:

```
https://raw.githubusercontent.com/msanie/sanie-ftp/main/FILENAME
```

Files inside a folder:

```
https://raw.githubusercontent.com/msanie/sanie-ftp/main/FOLDER/FILENAME
```

## How to add a file

1. Open this repo on github.com.
2. Select Add file, then Upload files.
3. Pick the files and select Commit changes.
4. Open the file, select Raw, and copy the URL.

## Rules

- This repo is public.  Anyone can browse every file here.  No confidential, client, or personal files.
- No spaces in file names.  Use hyphens: `q4-notes.pdf`, not `q4 notes.pdf`.
- Browser uploads cap at 25MB per file.
- Deleting a file from the repo does not erase it from the repo history.  Treat anything uploaded here as permanently public.

## Folders

| Folder | Contents |
| --- | --- |
| `docs/` | PDFs and text documents |
| `images/` | Images and diagrams |
| `data/` | CSV, JSON, and other data files |
| `temp/` | Short-term files.  Clear out monthly. |

## Notes

- Raw links serve HTML files as plain text.  Web pages show as code, not as rendered pages.
- PDFs, images, text, and data files work as expected.
